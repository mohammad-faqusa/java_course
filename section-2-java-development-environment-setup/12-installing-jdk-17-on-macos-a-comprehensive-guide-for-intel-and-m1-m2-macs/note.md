## 12. Installing JDK 17 on macOS: A Comprehensive Guide for Intel and M1/M2 Macs

### The process 
1. open browser `oracle.com`
2. browse to java 
2. download java SE 17 LTS 
3. choose `macOS`
4. two options : `arm64`, `x64` (choose according to your mac type)
5. click allow button 
6. open the downloaded setup 
7. installation complete
